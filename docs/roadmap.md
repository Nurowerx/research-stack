# Research roadmap

1. Invite independent reproduction of the released source and publish discrepancies with raw logs.
2. Add externally authored task families and domain datasets with clear redistribution rights; measure generalization separately from generator consistency.
3. Introduce authenticated per-user review identity, migration tests, cancellation and explicit interrupted-run recovery before broader hosted use.
4. Conduct a consented human-use study with a prespecified protocol before claiming usability or improved judgment.
5. Measure repeated isolated workloads, peak resource usage and larger graphs; add pagination and asynchronous workers where observations justify them.
6. Complete separate software, dataset and report archives once Zenodo access is available. Extend visualization comparisons and browser coverage without rewriting published observations.
