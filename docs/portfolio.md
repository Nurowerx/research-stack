# Scholarly portfolio record

Spencer H. Walker — Nurowerx — ORCID https://orcid.org/0009-0005-3574-1057.

Nurowerx Research Stack integrates an append-only evidence graph, deterministic evaluation engine, reviewed correction workflows and an interactive research console. The engineering contribution is a functioning connection between versioned source evidence, measured outputs, attributed review and reproducible reports. NRS-Bench provides original fixtures, known-answer and negative controls, paired comparisons and recorded reproduction procedures.

The work used AI-assisted implementation and manuscript preparation with executed validation. The release is a research-software artifact and three technical reports, not peer-reviewed publications or a human-subject study. No institutional sponsorship, independent replication or DOI is claimed without corresponding evidence.
