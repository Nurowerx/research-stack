# Repository instructions

Preserve TRACE / LOOP / LENS / FRAME architecture and unrelated projects. Do not force-push or rewrite published results. Keep raw observations, synthetic inputs and derived summaries separately labeled. Never invent tests, benchmark results, DOI values, participants or peer review.

Use the pinned Python and npm lock files. Run the checks in CONTRIBUTING.md appropriate to each change. New evidence-integrity behavior needs negative controls. Changes to plots must preserve denominators, units, missing values, uncertainty semantics and source identifiers. Do not treat deterministic repeat executions as independent samples.

Keep credentials, local databases, dependency caches and machine-specific paths out of commits. Software is MIT; original datasets and papers are CC BY 4.0. Public reference repositories are studied and cited; no Foundry service or copied enterprise data is required.
