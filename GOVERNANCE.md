# Governance

Nurowerx Research Stack is maintained by Spencer H. Walker through Nurowerx. No university sponsorship, peer review or independent certification is claimed. The initial implementation and release preparation used AI-assisted coding and writing with executed automated checks; this is not a claim of independent human verification.

The maintainer approves releases and scope changes. Contributors retain credit for identifiable work. Decisions affecting scientific claims require supporting observations, explicit limitations and reproducible methods. Release tags identify immutable versions; corrections are published in subsequent versions, never by rewriting an existing release history. Security patches may receive expedited review with a public explanation after disclosure is safe.

The current governance is maintainer-led, not a foundation or elected committee. Contributions and external reproduction reports are welcome.
