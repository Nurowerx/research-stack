# Community conduct

Treat contributors respectfully. Critique evidence and implementation without personal attacks. Harassment, threats, discriminatory abuse, impersonation and publication of private information are unacceptable.

Maintainer Spencer H. Walker is responsible for applying this policy consistently. Use GitHub's private reporting channels for platform abuse and the repository's private vulnerability reporting for security issues. Avoid putting sensitive personal details in public issues. Maintainers may edit or remove harmful content, restrict participation, or refer platform violations to GitHub. Decisions should explain the relevant behavior and allow a respectful appeal through the available GitHub channel.
